Create `web/src/stores/multiScenarioStore.ts` — a Zustand store managing N concurrent SSE connections with scenario-keyed state. Key design:

1. **State shape:**
```typescript
interface ScenarioState {
  label: string;
  color: string;         // SCENARIO_COLORS[index]
  dashPattern: string;   // SCENARIO_DASHES[index]
  sessionId: string;
  isRunning: boolean;
  isPaused: boolean;
  isComplete: boolean;
  currentIteration: number;
  totalIterations: number;
  macroHistory: TelemetryLog[];
  statsHistory: IterationStats[];
  feed: IterationFeed[];
  agents: Agent[];
  finalReport: string | null;
  error: string | null;
}

interface MultiScenarioStore {
  scenarios: Record<string, ScenarioState>;  // keyed by sessionId
  scenarioOrder: string[];  // ordered sessionId array for consistent rendering
  allComplete: boolean;
  anyRunning: boolean;
  
  initScenarios: (sessions: Array<{ id: string; label: string }>) => void;
  connectAll: () => () => void;  // Returns single cleanup fn
  pauseAll: () => Promise<void>;
  resumeAll: () => Promise<void>;
  abortAll: () => Promise<void>;
  addMoreIterations: (count: number) => Promise<void>;
  endAndProceed: () => Promise<void>;
  loadAllAgents: () => Promise<void>;
  loadAllHistory: () => Promise<void>;
  reset: () => void;
}
```

2. **Color/dash constants (per D-02, UI-SPEC):**
```typescript
export const SCENARIO_COLORS = ['var(--chart-blue)', 'var(--chart-orange)', 'var(--chart-green)', 'var(--chart-violet)'];
export const SCENARIO_DASHES = ['', '8 4', '4 4', '2 4'];
```

3. **initScenarios**: Creates scenario entries for each session. First session gets index 0 (blue, solid), etc. Up to 4 per D-08.

4. **connectAll**: For each scenario in `scenarioOrder`, open an EventSource to `/api/sessions/${sessionId}/simulate/stream`. Use the same RAF-batched flush pattern from simulationStore.connectSSE:
   - Buffer incoming SSE events in an array
   - On each RAF tick, flush all buffered events into Zustand state via a single `set()` call
   - Handle event types: `iteration-start` updates currentIteration/totalIterations, `iteration-complete` appends to statsHistory, `simulation-complete` sets isComplete=true and finalReport, `resolution` appends to feed, `error` sets error, `paused` sets isPaused
   - For `iteration-complete`, also fetch telemetry: `fetch(\`/api/sessions/${sessionId}/simulate/telemetry?from=${lastIter}\`)` and append to macroHistory
   - Return a single cleanup function that closes all EventSource connections

5. **pauseAll/resumeAll/abortAll**: Send POST requests to all running scenarios in parallel using `Promise.all`:
   ```typescript
   pauseAll: async () => {
     const running = Object.values(get().scenarios).filter(s => s.isRunning && !s.isPaused);
     await Promise.all(running.map(s => fetch(`/api/sessions/${s.sessionId}/simulate/pause`, { method: 'POST' })));
   }
   ```

6. **Derived state**: Recompute `allComplete` and `anyRunning` after every state update:
   ```typescript
   allComplete: Object.values(scenarios).length > 0 && Object.values(scenarios).every(s => s.isComplete)
   anyRunning: Object.values(scenarios).some(s => s.isRunning)
   ```

7. **loadAllAgents**: For each scenario, fetch `/api/sessions/${sessionId}/agents` and populate `agents` array.

8. **loadAllHistory**: For each scenario, fetch `/api/sessions/${sessionId}/simulate/telemetry` and `/api/sessions/${sessionId}/simulate/stats` and populate macroHistory/statsHistory.

9. **Export**: `export const useMultiScenarioStore = create<MultiScenarioStore>(...)` and export the SCENARIO_COLORS/SCENARIO_DASHES constants.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 700 (bold) | 1.3 |
| Heading | 16px | 700 (bold) | 1.2 |
| Display | 20px | 700 (bold) | 1.2 |

Two weights only: 400 (regular) for body text, data values, and chart tick labels; 700 (bold) for all non-body roles including labels, headings, display text, stat badges, scenario labels above progress bars, tab labels, config diff table headers, and tooltip iteration headers.

Source: Existing EconomicDashboard.tsx uses weight 700 for section titles. Standardized to 12px/14px/16px/20px for this phase. Previous 600 weight eliminated — all semibold usages promoted to 700.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--bg-color)` (#0d1117 dark / #ffffff light) | Page background, chart backgrounds |
| Secondary (30%) | `var(--glass-bg)` (rgba(255,255,255,0.03) dark / rgba(255,255,255,0.6) light) | Chart cards, panel backgrounds, collapsed strip, config diff header |
| Accent (10%) | `var(--primary)` (#4f46e5) | "View Full Comparison" CTA button, active scenario tab indicator, pause/resume button fills |
| Destructive | `var(--danger)` (#ef4444 dark / #dc2626 light) | Abort button, error badges |

Accent reserved for: "View Full Comparison" button, "Run All Scenarios" button, active tab underlines in Live Feed/Agent Status scenario tabs, primary action buttons in top bar (resume). NOT used for chart lines or scenario colors.

### Scenario Color Palette (4 colors, colorblind-safe)

These are dedicated chart series colors for distinguishing scenarios. They are NOT accent colors.

| Scenario Index | Color Token | Hex (dark) | Dash Pattern | Usage |
|----------------|-------------|------------|--------------|-------|
| 0 (Baseline) | `var(--chart-blue)` | #60a5fa | solid (`""`) | First/baseline scenario line on all charts, stat badges, progress bar, legend |
| 1 (Scenario A) | `var(--chart-orange)` | #f97316 | long dash (`"8 4"`) | Second scenario line, badges, progress bar, legend |
| 2 (Scenario B) | `var(--chart-green)` | #4ade80 | short dash (`"4 4"`) | Third scenario line, badges, progress bar, legend |
| 3 (Scenario C) | `var(--chart-violet)` | #a78bfa | dotted (`"2 4"`) | Fourth scenario line, badges, progress bar, legend |

Source: D-02 (color + dash patterns for colorblind accessibility), D-08 (max 4 scenarios). Colors chosen from existing `--chart-*` tokens in `index.css` for theme consistency. Blue/orange/green/violet provide maximum perceptual distance for both dark and light themes.

## Layout Contract

### Simulation Page — 3-Column Layout

```
+----------------------------------------------------------------------+
| TOP BAR: [Progress bars per scenario] [Pause] [Resume] [Abort] [End] |
+----------------------------------------------------------------------+
| CONFIG DIFF HEADER (collapsible): param differences across scenarios  |
+----------------------------------------------------------------------+
| LIVE FEED     | STATISTICS (scrollable)     | AGENT STATUS           |
| (collapsible) | Chart grid (1-col or 2-col) | (collapsible)          |
| Col 1: 300px  | Col 2: flex-1               | Col 3: 300px           |
+----------------------------------------------------------------------+
```

**Panel widths:**
- Live Feed (Col 1): `minWidth: 300px` expanded, `width: 40px` collapsed
- Statistics (Col 2): `flex: 1` (fills remaining space)
- Agent Status (Col 3): `minWidth: 300px` expanded, `width: 40px` collapsed

**Collapse behavior (D-23, D-24, D-29):**
- Each side panel has a collapse button positioned at top-right (Live Feed) or top-left (Agent Status)
- Collapsed panel renders as a 40px-wide vertical strip with a centered expand icon (ChevronRight for left panel, ChevronLeft for right panel) using `lucide-react`
- Transition: `width 0.3s ease, min-width 0.3s ease`; `overflow: hidden`
- Statistics panel uses CSS grid: `grid-template-columns: repeat(auto-fill, minmax(420px, 1fr))` when both neighbors collapsed; single column otherwise
- Collapse state is React `useState`, resets on page mount (D-29)

**Chart grid within Statistics:**
- Default (both panels expanded): single column, each chart full width
- One panel collapsed: single column, wider charts
- Both panels collapsed: `display: grid; grid-template-columns: repeat(auto-fill, minmax(420px, 1fr)); gap: 32px`

### Chart Order (D-25)

All charts rendered at identical dimensions: `ResponsiveContainer width="100%" height={200}`.

### Top Bar — Multi-Progress

```
+----------------------------------------------------------+
| [Baseline ====70%====] [Policy A ===50%===] [Abort] [End]|
| [Policy B ===50%===]   [Policy C ===50%===] [Pause]      |
+----------------------------------------------------------+
```

- Progress bars stacked in a flex-wrap container: `display: flex; flex-wrap: wrap; gap: 8px; flex: 1`
- Each bar: `height: 8px; border-radius: 4px; background: var(--panel-alpha-10)`; fill uses scenario color at 80% opacity
- Scenario label above each bar: 12px, weight 700, scenario color
- "Complete" text replaces percentage when a scenario finishes (D-13)
- Controls grouped at right: Pause/Resume (toggle), Abort, End & Proceed (D-32, D-34)

### Scenario Tabs in Side Panels (D-26)

When N>1, Live Feed and Agent Status panels show horizontal tabs at their top:

```
[Baseline] [Policy A] [Policy B]
------------------------------
(content for selected scenario)
```

- Tab style: 12px weight 700, `color: var(--text-dim)` inactive, scenario color active
- Active indicator: 2px bottom border in scenario color
- Tab container: `display: flex; gap: 4px; border-bottom: 1px solid var(--glass-border); padding-bottom: 4px; margin-bottom: 8px`

## Interaction States

### Chart Tooltip (D-09)

Shared crosshair tooltip shows all scenario values at hovered iteration:

```
Iteration 15
---------------------
Baseline:  102.3
Policy A:  108.7
Policy B:   99.1
```

- Background: `var(--bg-color)`
- Border: `1px solid var(--primary)`
- Border radius: 8px
- Padding: 8px 12px
- Each scenario value prefixed with a colored circle (8px diameter, scenario color)
- Font: 12px weight 400 for values, 12px weight 700 for iteration header
- Value color matches scenario color

### Progress Bar States

| State | Visual |
|-------|--------|
| Running | Filled bar in scenario color (80% opacity), label shows "{N}%" |
| Paused | Filled bar + pulsing opacity animation (`opacity: 0.5 -> 1.0`, 1.5s ease-in-out infinite`) |
| Complete | Full bar in scenario color, label shows "Complete" in `var(--success)` |
| Error | Bar fill in `var(--danger)`, label shows "Error" |

### Panel Collapse Animation

- Duration: 300ms
- Easing: `ease`
- Properties animated: `width`, `min-width`, `opacity` (content fades out at 150ms, panel shrinks 150-300ms)
- Collapsed strip: `background: var(--glass-bg); border: 1px solid var(--glass-border)`

### N=1 vs N>1 Behavior (D-22)

No mode switching. N=1 shows:
- Single line per chart in scenario color index 0 (blue, solid)
- Single progress bar
- No scenario tabs in side panels
- No config diff header (nothing to diff)
- "View Full Comparison" button does NOT appear (needs 2+ sessions)

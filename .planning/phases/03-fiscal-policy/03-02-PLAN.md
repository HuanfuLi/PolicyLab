    **FiscalDelta interface:**
    ```typescript
    export interface FiscalDelta {
      treasuryDelta: number;              // negative (spending deducted from treasury)
      welfarePayments: Map<string, number>; // agentId -> welfare payment amount
      updatedPublicGoods: Omit<PublicGoodsState, 'id' | 'sessionId'>;  // new quality scores
      multiplierEffects: MultiplierEffects;
      trace: string[];
    }

    export interface MultiplierEffects {
      productivityBonus: number;   // from infrastructure quality (multiplier on PRODUCE/WORK output)
      skillGainBonus: number;      // from education quality (multiplier on skill XP gain)
      enforcementBonus: number;    // from defense quality (multiplier on enforcement_level)
      welfarePerAgent: number;     // from welfare spending (direct fiat per agent this iteration)
    }
    ```

    **executeBudget function:**
    ```typescript
    export function executeBudget(params: {
      treasuryBalance: number;
      budgetAllocation: BudgetAllocation;
      economyConfig: EconomyConfig;
      currentPublicGoods: Omit<PublicGoodsState, 'id' | 'sessionId'>;
      aliveAgentCount: number;
      iterationNumber: number;
    }): FiscalDelta
    ```

    Logic:
    1. Compute total spending: `treasuryBalance * (economyConfig.budgetSpendingRate ?? 0.10)`
    2. If treasury <= 0 or total spending <= 0: return zero-delta with quality decay only
    3. Allocate spending per category: `totalSpending * budgetAllocation.{category}`
    4. **Welfare** — distributed equally to all alive agents: `welfareSpending / aliveAgentCount` per agent. This is a direct treasury-to-agent transfer (SFC-neutral). DO NOT use quality score for welfare — it is a direct payment.
    5. **Infrastructure/Education/Defense** — spending flows into quality scores via `updatePublicGoodsQuality`. Quality gain formula: `gain = (spendAmount ^ diminishingExponent) * scaleFactor`. Scale factor chosen so that spending 25 fiat (with 1000 treasury, 0.10 rate, 0.25 allocation) produces ~2-3 quality points gain.
    6. Apply decay to all quality categories where spending is zero or below threshold: `quality -= decayRate`
    7. Clamp all quality scores to [0, 100]
    8. Compute multiplier effects from UPDATED quality scores:
       - productivityBonus = infrastructureQuality * infrastructureMultiplier
       - skillGainBonus = educationQuality * educationMultiplier
       - enforcementBonus = defenseQuality * defenseMultiplier
       - welfarePerAgent = welfareSpending / aliveAgentCount (already computed)
    9. treasuryDelta = -(sum of all category spending) — must equal total spending exactly
    10. Build trace strings for each category action

    **Key constraints:**
    - Treasury never goes negative: if treasuryBalance < totalSpending, scale down proportionally (FISC-04)
    - All fiat is accounted for: treasuryDelta + sum(welfarePayments) = 0 (the infrastructure/education/defense spending is also from treasury but does NOT go to agents — it is "consumed" for public goods, effectively removed from circulation). WAIT — this breaks SFC. Rethink:
      - Actually, government spending on infrastructure/education/defense in the real world pays workers. In this simulation, the simplest SFC-compliant model: ALL spending goes to agents (distributed equally or by role), and the quality score tracks the CUMULATIVE investment effect. This way treasury -> agents is a pure wealth transfer, SFC-neutral.
      - OR: infrastructure/education/defense spending goes to the AMM as "government purchases" — but that is complex.
      - SIMPLEST SFC-compliant approach: All budget spending is distributed to agents (welfare is explicit, others are implicit "government employment"). The quality score tracks cumulative investment separately. treasuryDelta = -(totalSpending). Sum of all agent payments = totalSpending. Net = 0.

    Revised design for SFC compliance:
    - ALL four categories distribute fiat to agents (SFC requirement: money cannot disappear)
    - Infrastructure spending: distributed to agents proportionally (simulates government contracts)
    - Education spending: distributed to agents proportionally (simulates education subsidies)
    - Defense spending: distributed to agents proportionally (simulates defense employment)
    - Welfare spending: distributed to agents proportionally (direct transfers)
    - Quality scores track cumulative investment (they are a SIDE EFFECT of spending, not a store of value)
    - This means: treasuryDelta + sum(all agent payments across all categories) = 0

    Update FiscalDelta:
    ```typescript
    export interface FiscalDelta {
      treasuryDelta: number;                    // negative
      agentPayments: Map<string, number>;       // agentId -> total payment (sum of all categories)
      updatedPublicGoods: { iterationNumber: number; infrastructureQuality: number; educationQuality: number; defenseQuality: number; welfareQuality: number };
      multiplierEffects: MultiplierEffects;
      trace: string[];
    }
    ```

    The agentPayments map distributes ALL spending equally to alive agents. Quality scores update based on category-specific spending amounts.

    2. Normal budget -> correct treasury deduction, agent payments sum to spending
    3. Insufficient treasury -> proportional scaling (FISC-04)

    5. Quality clamped at 0 and 100
    6. SFC invariant: treasuryDelta + sum(agentPayments.values()) === 0
    7. Multiplier effects computed from updated quality scores
    8. Zero allocation for a category -> that category's quality decays

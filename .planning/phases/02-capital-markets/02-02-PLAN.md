**CapitalMarketDelta interface:**
```typescript
export interface CapitalMarketDelta {
  upsertEquityPositions: EquityPosition[];
  upsertBondHoldings: BondHolding[];
  deleteBondHoldingIds: string[];
  wealthDeltas: Map<string, number>;
  treasuryDelta: number;
  enterpriseTreasuryDeltas: Map<string, number>;
  trace: string[];
}
```

**Key functions to implement:**
1. `processSharePurchase(params)` — buyer wealth → enterprise owner wealth; creates/updates EquityPosition with weighted average cost basis
2. `processShareSale(params)` — reverse of purchase; seller shares decrease, buyer shares increase, wealth transfers
3. `distributeDividends(params)` — uses `distributeProRata` from `@policylab/shared` (shared/src/math.ts); total dividend = `Math.floor(ownerWealth * dividendPayoutRatio)`; owner wealth decreases, shareholders gain pro-rata
4. `processGovBondPurchase(params)` — buyer wealth → treasury; creates BondHolding with status='active', bondType='government', issuerId='treasury'
5. `processCorpBondIssuance(params)` — buyer wealth → enterprise owner wealth; creates BondHolding with bondType='corporate', issuerId=enterpriseOwner agentId
6. `processCoupons(holdings, currentIteration)` — for each active holding: compute coupon = faceValue * couponRate; holder wealth +=, issuer balance -= (treasury or enterprise owner)
7. `processMaturities(holdings, currentIteration)` — for holdings where currentIteration >= maturityIteration: return principal, mark for deletion
8. `processIteration(params)` — main orchestrator: takes session agents, existing positions/holdings, pending requests, economyConfig; returns single CapitalMarketDelta

**SFC invariant:** Every function must have net zero wealth change across all parties. Use comments like `// SFC: buyer -X, seller +X, net=0`.

**Import distributeProRata from `@policylab/shared`** — it is exported from `shared/src/math.ts`. Do NOT re-implement it.

**Share price formula:** `enterpriseOwner.wealth / totalSharesOutstanding` for secondary trades. For IPO (no existing shares), use a fixed 10 fiat per share (from physicsConfig/economyConfig, or hardcode 10 as a sensible default for v1).

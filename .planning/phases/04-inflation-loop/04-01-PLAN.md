2. Create `server/src/mechanics/inflationEngine.ts` as a **pure function module** with zero DB imports:

   ```typescript
   export interface InflationInput {
     iterationNumber: number;
     currentPrices: Record<string, number>;   // keyed by basket item name
     basePrices: Record<string, number>;       // from iteration 1
     m1Current: number;
     m1Previous: number | null;               // null on iteration 1
     previousCpi: number | null;              // null on iteration 1
     recentCpiHistory: number[];              // last N CPI values for smoothing
     economyConfig: EconomyConfig;
   }

   export interface InflationOutput {
     cpi: number;
     inflationRate: number;
     inflationExpectations: number;
     ammFeedbackFactor: number;
     trace: string[];
   }

   export function computeInflation(input: InflationInput): InflationOutput
   ```

   **CPI computation (Laspeyres fixed-base):**
   - Get basket weights from `economyConfig.cpiBasketWeights` or DEFAULT_CPI_BASKET_WEIGHTS
   - CPI = sum over each basket item: weight_i * (currentPrice_i / basePrice_i) * 100
   - If a basket item has no current price, use basePrice (ratio = 1.0) to avoid distortion

   **Inflation rate:**
   - If previousCpi is null (iteration 1): inflationRate = 0
   - Otherwise: inflationRate = ((cpi / previousCpi) - 1) * 100

   **M1 signal blending:**
   - If m1Previous is null: m1Signal = 0
   - Otherwise: m1GrowthRate = (m1Current - m1Previous) / m1Previous
   - m1Signal = m1GrowthRate - productivityGrowthEstimate (default 0.01)
   - blendedInflation = (1 - alpha) * inflationRate + alpha * m1Signal * 100
     where alpha = economyConfig.m1InflationCoeff (default 0.3)

   **Inflation expectations (rolling mean):**
   - If recentCpiHistory has fewer than 2 values: expectations = inflationRate
   - Otherwise: compute inflation rates between consecutive CPI values in history, take mean
   - This is a simple rolling average, NOT an EMA (per research: "Simple rolling mean over 3-5 values")

   **AMM feedback factor:**
   - threshold = economyConfig.inflationAmmThreshold (default 0.5)
   - cap = economyConfig.inflationAmmCap (default 2.0)
   - If |inflationExpectations| < threshold: ammFeedbackFactor = 1.0
   - Otherwise: rawFactor = 1 + (inflationExpectations / 100) * alpha
     where alpha = economyConfig.m1InflationCoeff (default 0.3)
   - Clamp: ammFeedbackFactor = Math.min(rawFactor, 1 + cap/100) and Math.max(rawFactor, 1 - cap/100)

   **Trace:** Include each computation step as a string in the trace array for physics trace log injection.

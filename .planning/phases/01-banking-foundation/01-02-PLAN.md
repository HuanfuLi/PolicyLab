    **Per BANK-01, BANK-02, BANK-03, BANK-04, BANK-05:**

    Create `server/src/mechanics/bankingEngine.ts` as a module of pure-ish functions (DB reads happen via bankingRepo, but all mutations are collected as deltas and returned):

    **Key design:** Functions return delta objects rather than directly mutating DB. The caller (simulationRunner in Plan 03) applies deltas in batch.

    ```typescript
    // Types for return values
    export interface BankingDelta {
      depositUpdates: Array<{ accountId: string; newBalance: number; iteration: number }>;
      loanUpdates: Array<{ loanId: string; updates: Partial<LoanContract> }>;
      wealthDeltas: Map<string, number>; // agentId -> wealth change (for collateral/interest base money moves)
      newLoans: LoanContract[];
      newDeposits: Array<Omit<DepositAccount, 'id'>>;
      balanceSheetSnapshots: BankBalanceSheet[];
      trace: string[]; // physics trace log entries
    }
    ```

    **Exported functions:**

    1. `canIssueLoan(bankReserves: number, totalDeposits: number, requestedPrincipal: number, reserveRequirement: number): boolean`
       - Returns `bankReserves / (totalDeposits + requestedPrincipal) >= reserveRequirement`
       - Edge case: if totalDeposits + requestedPrincipal === 0, return true (no deposits yet)

    2. `processLoanRequest(params: { bank: Agent, borrower: Agent, principal: number, economyConfig: EconomyConfig, currentDeposits: DepositAccount[], iterationNumber: number }): { loan: LoanContract, collateralAmount: number, borrowerWealthDelta: number } | { rejected: true, reason: string }`
       - Check canIssueLoan; reject if false
       - collateralAmount = Math.min(borrower.currentStats.wealth * 0.5, principal)
       - Create LoanContract: id=uuidv4(), interestRate=economyConfig.baseLoanInterestRate, termIterations=economyConfig.defaultLoanTermIterations, remainingBalance=principal, dueAtIteration=iterationNumber+termIterations, status='active'
       - borrowerWealthDelta = -collateralAmount (collateral escrowed from cash-on-hand)
       - Borrower's deposit increases by principal (M1 expansion) — returned as deposit delta

    3. `processRepayment(loan: LoanContract, borrowerDeposit: DepositAccount, paymentAmount: number): { loanUpdate: Partial<LoanContract>, depositDelta: number, bankReservesDelta: number }`
       - Split payment into principal and interest: interest = loan.remainingBalance * loan.interestRate; principalPaid = paymentAmount - interest
       - If paymentAmount < interest: all goes to interest, no principal reduction, but still counts as partial payment (consecutiveMissed stays 0 or resets)
       - depositDelta = -paymentAmount (borrower deposit decreases)
       - bankReservesDelta = +interest (bank gets real base money)
       - loanUpdate: remainingBalance -= principalPaid; if remainingBalance <= 0, status = 'repaid', consecutiveMissed = 0

    4. `accrueInterest(loan: LoanContract, borrowerDeposit: DepositAccount, economyConfig: EconomyConfig): { depositDelta: number, bankReservesDelta: number, loanUpdate: Partial<LoanContract> }`
       - interest = loan.remainingBalance * loan.interestRate
       - If borrowerDeposit.balance >= interest: depositDelta = -interest, bankReservesDelta = +interest, consecutiveMissed = 0
       - Else: consecutiveMissed += 1 (cannot pay), depositDelta = 0, bankReservesDelta = 0

    5. `processDefault(loan: LoanContract, bankAgent: Agent): { loanUpdate: Partial<LoanContract>, bankWealthDelta: number, trace: string }`
       - Set loan status = 'defaulted'
       - bankWealthDelta = +loan.collateralAmount (collateral transferred to bank reserves)
       - loss = loan.remainingBalance - loan.collateralAmount (bank absorbs loss)
       - trace = `[BANK] Loan ${loan.id} defaulted. Collateral ${loan.collateralAmount} seized. Bank loss: ${loss}`

    6. `accrueDepositInterest(deposits: DepositAccount[], bankAgent: Agent, economyConfig: EconomyConfig): { depositUpdates: Array<{id: string, newBalance: number}>, bankReservesDelta: number }`
       - For each deposit: interestPaid = deposit.balance * economyConfig.depositInterestRate
       - Total interest = sum of all interestPaid
       - If bankAgent.currentStats.wealth >= total interest: pay all. Else: pro-rate using available reserves.
       - bankReservesDelta = -totalInterestPaid

    7. `processIteration(params: { sessionId: string, bankAgents: Agent[], allAgents: Agent[], loans: LoanContract[], deposits: DepositAccount[], economyConfig: EconomyConfig, iterationNumber: number }): BankingDelta`
       - Order: (1) accrueInterest on each active loan, (2) check for defaults (consecutiveMissed >= defaultThresholdIterations), (3) accrueDepositInterest, (4) snapshot balance sheets
       - Collect all deltas into a single BankingDelta return value

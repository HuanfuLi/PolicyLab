# Plan 10-GC4: Bootstrap Hardening + Stagnation-Detector Investigation Summary

**D-27 stub-background abort guard landed, roster LLM calls batched to fit local models, JSON Schema structured output replaces fragile regex-fallback parsing. Investigated the "7/10 iterations" stagnation report — confirmed no spurious early stop.**

## Performance

- **Duration:** Iterated across 5 commits between `74c79f3` and `c82dcab`
- **Tasks:** 3 planned (stub guard, stagnation recalibration, human UAT) — see Deviations
- **Files modified:** 4 (+ 0 created)

## Accomplishments
- **D-27 (stub backgrounds):** Bootstrap now scans every blueprint after LLM enrichment for the placeholder string `"background to be generated by llm"` (case-insensitive). If any remain, bootstrap emits an SSE error and aborts before persisting to DB. Prevents the China-session failure mode where 51 agents had stub backgrounds.
- **Roster batching:** 50-agent roster generation was exceeding local-model output token caps (typically 2048-4096), causing truncation → JSON parse failure → silent stub fallthrough. Now batched into groups of 10 (~800-1200 tokens/call). Any batch failure aborts the whole bootstrap with a clear error.
- **JSON Schema structured output:** Added `LLMOptions.jsonSchema` field; `OpenAICompatibleProvider` maps it to `response_format.json_schema`. Gemma-class local models that produced `_name":` prefixes, unquoted keys, and missing braces now emit well-formed JSON. Anthropic / Gemini providers accept-and-ignore the field.
- **Stagnation-detector investigation:** Grepped simulationRunner.ts for `stagnation`, `earlyStop`, `low variance`, `action variety`. Found no such detector — the only early-stop is the regime-collapse guard (cortisol ≥ 95 or happiness ≤ 5). The China-session "7/10 iterations" observation was the user passing `iterations=7` via the API, not a code-level premature halt. Added an explanatory comment to prevent future false alarms.

## Decisions Made
- **Regex fallback → schema:** An initial attempt (commits 6ebbe54, 6b2c7d0) added regex-based recovery for malformed LLM JSON. Worked in some cases but fragile against novel model drift. Replaced in `c82dcab` with structured-output schema — deterministic at the generation boundary, removes the whole class of bugs instead of pattern-matching specific hallucinations.
- **Uniform API across providers:** `jsonSchema` is accepted by all providers but only honored by OpenAI-compatible. Avoids branching call sites on provider identity.
- **Batch size 10:** Empirically-chosen to fit any local model's output context window while keeping total round trips manageable for the default 50-agent roster.

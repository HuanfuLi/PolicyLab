<objective>
Fix the final two simulation realism gaps identified in the China session:

**Gap 1 — D-27: Bootstrap stub background validation not enforced**

The China session has all 51 agents with `"background": "Background to be generated by LLM"` — placeholder text that should have caused the bootstrap to abort. The D-27 requirement states: "If agent background LLM enrichment fails during location bootstrap, fail the entire bootstrap. No sessions with stub backgrounds."

The plan 03 implementation added abort-on-error for the LLM call itself, but did NOT add a post-LLM check verifying that backgrounds were actually populated (not stubs). The fix: after the background enrichment LLM call, inspect each agent's background and abort if any still contain the stub string.

**Gap 2 — Simulation stopped at 7/10 iterations (stagnation detector)**

The China session configured 10 iterations but only completed 7. The early-stopping detector triggered, likely because with no enterprise activity (subsistence-only agents), economic variance was too low. The stagnation detector was calibrated for pre-enterprise simulations. With active enterprises (after GC1 fix), more economic activity occurs — but the thresholds may still fire incorrectly if the detector looks at action variety or wealth variance. This plan identifies the detector's exact thresholds and recalibrates them.

**Gap 3 — Final human verification**

After all 3 prior gap closure plans are applied, this plan gates on a human-verified simulation run confirming the fixes actually work end-to-end: enterprise wages paid, CPI moving, banking used.
</objective>

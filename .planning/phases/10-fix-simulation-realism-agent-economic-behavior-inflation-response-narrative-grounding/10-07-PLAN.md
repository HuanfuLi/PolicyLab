**1. Add runtime assertions for agent data injection (D-22):**

In simulationRunner.ts, find where agent context is built before the intent LLM call (the cognitive/intent phase). Add assertions:

```typescript
// Runtime assertion: verify agent context includes accurate personal data (D-22)
function assertAgentContext(agentId: string, context: any, agent: Agent): void {
  if (typeof context.wealth !== 'number' || isNaN(context.wealth)) {
    console.warn(`[ASSERTION] Agent ${agentId}: wealth is not a valid number (got ${context.wealth})`);
  }
  if (typeof context.health !== 'number' || isNaN(context.health)) {
    console.warn(`[ASSERTION] Agent ${agentId}: health is not a valid number (got ${context.health})`);
  }
  if (Math.abs((context.wealth ?? 0) - (agent.currentStats?.wealth ?? 0)) > 0.01) {
    console.warn(`[ASSERTION] Agent ${agentId}: context wealth (${context.wealth}) differs from agent wealth (${agent.currentStats?.wealth})`);
  }
}
```

Call this function before each agent intent LLM call, passing the context object and the agent's current stats. This catches cases where stale or incorrect data is injected into the prompt.

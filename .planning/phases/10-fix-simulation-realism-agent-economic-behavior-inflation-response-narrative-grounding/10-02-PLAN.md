2. `EnterpriseDelta` interface:
```typescript
export interface EnterpriseDelta {
  wagePayments: Array<{ fromEnterprise: string; toAgentId: string; amount: number }>;
  productionOutput: Array<{ enterpriseId: string; commodity: EnterpriseCommodity; quantity: number }>;
  insolvencyUpdates: Array<{ enterpriseId: string; consecutiveDeficits: number; isBankrupt: boolean }>;
  liquidations: Array<{ enterpriseId: string; commodity: EnterpriseCommodity; quantity: number }>;
  idleFallbackProduction: Array<{ agentId: string; commodity: 'food'; quantity: number }>;
  costPassThroughMarkup: Map<string, number>; // enterpriseId -> price markup factor
  trace: string[];
}
```

3. `processEnterpriseWages(params)` -- per D-05, D-06, D-07:
   - Input: enterprise records, worker action lists (which agents did WORK this iteration), economyConfig, insolvency counters
   - For each enterprise: sum wages for workers who WORKED. Enforce `minimumWage` floor (use `Math.max(enterprise.wage, config.minimumWage ?? 5)`).
   - If enterprise treasury >= total wage bill: pay all, reset insolvency counter to 0
   - If enterprise treasury < total wage bill: pro-rata partial pay (`treasury / totalWageBill * individualWage`), increment insolvency counter
   - Return EnterpriseDelta with wagePayments and insolvencyUpdates

4. `processEnterpriseInsolvency(params)` -- per D-06:
   - Input: insolvency counters, enterprise records, economyConfig
   - For each enterprise where `counter >= (config.enterpriseInsolvencyThreshold ?? 3)`: mark bankrupt, generate liquidation deltas (sell all inventory to AMM)
   - Employees of bankrupt enterprises returned in trace for removal from employment registry

5. `processIdleFallback(params)` -- per D-09:
   - Input: agent idle counters, agent action lists this iteration, economyConfig
   - For each agent: if action list contains WORK, WORK_AT_ENTERPRISE, PRODUCE_AND_SELL, or PRODUCE -> reset counter to 0
   - Otherwise: increment counter. If counter >= (config.idleFallbackThreshold ?? 2) -> add forced food production of (config.idleFallbackProduction ?? 5) to delta
   - Return idleFallbackProduction entries

6. `processEnterpriseProduction(params)` -- per D-11:
   - Input: enterprise records with production quantities for this iteration
   - Map each enterprise to its commodity type via sectorToCommodity
   - Return productionOutput entries (what to sell to AMM)

7. `processEnterpriseCostPassThrough(params)` -- per D-10:
   - Input: enterprise wage costs this iteration vs previous iteration
   - When wage costs rise, compute markup factor: `1 + (wageCostDelta / previousWageCost) * 0.5` (50% pass-through)
   - Return costPassThroughMarkup map

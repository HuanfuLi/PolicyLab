**2. Add `processLiquidityInjection` to `server/src/mechanics/bankingEngine.ts`:**

```typescript
export function processLiquidityInjection(params: {
  bankReserves: number;
  totalDeposits: number;
  config: EconomyConfig;
}): { injectionAmount: number; trace: string[] }
```

Implementation:
- Compute actual reserve ratio: `bankReserves / Math.max(totalDeposits, 1)`
- If ratio < `(config.liquidityInjectionThreshold ?? 0.05)`:
  - `injectionAmount = Math.min(totalDeposits * (config.liquidityInjectionCap ?? 0.05), totalDeposits * (config.liquidityInjectionThreshold! - actualRatio))`
  - Trace: `[CB] Liquidity injection: ${injectionAmount.toFixed(2)} fiat (reserves at ${(actualRatio*100).toFixed(1)}%, threshold ${((config.liquidityInjectionThreshold ?? 0.05)*100).toFixed(1)}%)`
- Else: `injectionAmount = 0`, empty trace
- Return `{ injectionAmount, trace }`

NOTE: The injection is an M0 increase -- the simulationRunner must account for this in the SFC audit by adjusting the M0 baseline. Add a comment in the function noting this.

**3. Create `generateEnterprises` in `server/src/data/dataBootstrapPipeline.ts`:**

Export a new function after `generateAgentRoster`:
```typescript
export function generateEnterprises(
  agents: Agent[],
  profile: LocationProfile | null,
  baseFiat: number,
  minimumWage: number,
): EnterpriseBlueprint[]
```

Implementation:
- Group agents by sector (use the agent.role field, map to EnterpriseSector via a helper: farmer/agriculture/fisherman -> 'agriculture', factory/manufacturing/mining -> 'industry', merchant/artisan/trader -> 'services', teacher/doctor/official/military/police -> 'government')
- For each sector (except 'government' which is handled separately):
  - Determine enterprise count: if `profile?.economics?.enterpriseDensity?.value` exists, use `Math.round(density * agents.length / 1000)` clamped to [1, 3]; else fallback to `Math.max(1, Math.min(3, Math.ceil(sectorAgents.length / 5)))`
  - Select owners: filter sector agents by `getRoleTier(agent.role) !== 'laborer'`, take first N as owners. If no eligible owner, use highest-wealth agent.
  - Compute initial capital: `(profile?.economics?.gdpPerCapita?.value ?? 10000) * 0.3`
  - Compute initial wage: `Math.max(minimumWage, baseFiat * 0.05)`
  - Map sector to commodity using the same mapping as enterpriseEngine: agriculture->food, industry->tools, services->luxury_goods
  - Seed initial inventory by sector: agriculture gets `{food: Math.round(initialCapital * 0.3)}`, industry gets `{tools: Math.round(initialCapital * 0.2), raw_materials: Math.round(initialCapital * 0.1)}`, services gets `{luxury_goods: Math.round(initialCapital * 0.15)}`
  - Distribute remaining agents as employees across enterprises in the sector (round-robin)
  - Enterprise IDs: `ent_${sector.slice(0,4)}_${index+1}` (e.g., `ent_agri_1`, `ent_indu_2`)
  - Enterprise names: formulaic like "Farm Enterprise 1", "Factory Enterprise 2" etc (LLM enrichment can rename later)
- For 'government' sector: create service enterprises (schools, clinics) with `isServiceEnterprise: true`, `commodityOutput: 'none'`. Capital comes from state treasury proportional to fiscal budget.
- Return all EnterpriseBlueprint[]

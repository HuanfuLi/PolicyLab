--- Panel 1: CPI Line Chart ---
Title: "CPI — Laspeyres Price Index"
Data source: data.filter(d => d.cpi != null)
Empty state (when filtered array is empty): render a styled div with text
  "No CPI data — requires Phase 4 (Inflation Loop)"
When data present:
  - XAxis: dataKey="iterationNumber", label "Iteration"
  - YAxis: domain auto, tickFormatter rounds to 1 decimal
  - Line: dataKey="cpi", stroke=CHART_BLUE, strokeWidth=2, dot=false, name="CPI"
  - Smoothed trend overlay: compute 5-point EWMA inline before rendering.
    EWMA formula: `ema[i] = alpha * cpi[i] + (1-alpha) * ema[i-1]`, alpha=0.3, seed=cpi[0].
    Add this as a second `data` field "trend" to each point object, render as a second Line
    with stroke=CHART_ORANGE, strokeDasharray="5 3", name="Trend (EWMA)", dot=false.

--- Panel 2: Money Supply Area Chart ---
Title: "Money Supply — M0 / M1 / M2"
Data source: data.filter(d => d.m0 != null || d.m1 != null)
Empty state: "No banking data — requires Phase 1 (Banking Foundation)"
When data present:
  - XAxis: dataKey="iterationNumber"
  - YAxis: tickFormatter uses fmt helper (K/M abbreviation)
  - AreaChart with stackId="money" stacking:
      Area 1: dataKey="m0", fill=CHART_BLUE (20% opacity), stroke=CHART_BLUE,
              fillOpacity=0.25, name="M0 (Base Money)", stackId="money"
      Area 2: dataKey for M1-M0 spread: compute `m1Delta = (m1 ?? m0 ?? 0) - (m0 ?? 0)`,
              add as "loanExpansion" field in mapped data array.
              Area: dataKey="loanExpansion", fill=CHART_GREEN (40% opacity), stroke=CHART_GREEN,
              fillOpacity=0.4, name="Loan Expansion (M1-M0)", stackId="money"
      Area 3 (if m2 data present): compute `m2Delta = (m2 ?? m1 ?? m0 ?? 0) - (m1 ?? m0 ?? 0)`,
              add as "m2Delta". Area: dataKey="m2Delta", fill=CHART_VIOLET, fillOpacity=0.3,
              name="M2 Layer", stackId="money"
  - IMPORTANT: map data to computed objects before passing to AreaChart to avoid recharts
    computing stacking from undefined fields. Use `data.map(d => ({ iterationNumber: d.iterationNumber,
    m0: d.m0 ?? 0, loanExpansion: Math.max(0, (d.m1 ?? d.m0 ?? 0) - (d.m0 ?? 0)),
    m2Delta: Math.max(0, (d.m2 ?? d.m1 ?? d.m0 ?? 0) - (d.m1 ?? d.m0 ?? 0)) }))`.

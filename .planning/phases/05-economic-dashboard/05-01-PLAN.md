3. Add to initialState:

4. In `loadHistory`: after `set({ feed, statsHistory, currentIteration: ... })`, call a new
   helper to fetch telemetry and set macroHistory. Add a new action `loadMacroHistory`:
```typescript
loadMacroHistory: async (sessionId: string) => {
  try {
    const res = await fetch(`/api/sessions/${sessionId}/simulate/telemetry`);
    if (!res.ok) return;
    const data = await res.json() as TelemetryLog[];
    set({ macroHistory: data ?? [] });
  } catch { /* ignore */ }
},
```

5. In `loadHistory` body, after the existing `set({...})` call, add:
```typescript
get().loadMacroHistory(sessionId);
```

6. In the `iteration-complete` handler inside `flushBuffer` (the `set(state => ...)` block):

   flag `needMacroReload = true` (parallel to `needAgentReload`). After the set() call, add:
```typescript
if (needMacroReload) {
  get().loadMacroHistory(sessionId);
}
```
   Set `needMacroReload = true` inside the `iteration-complete` case (same place as `needAgentReload = true`).

7. Expose `loadMacroHistory` in the SimulationStore interface as:
```typescript
loadMacroHistory: (sessionId: string) => Promise<void>;
```

8. Add `macroHistory` and `loadMacroHistory` to the `reset` action's initialState spread

IMPORTANT: Do NOT break the existing raf double-buffer pattern. The needMacroReload flag
follows the same pattern as needAgentReload — declared before the batch loop, set inside
the case, acted on after the set() returns.
